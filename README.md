# Nhom16 - Hệ thống quản lý sân bóng tại Đà Nẵng

## Giới thiệu
Dự án xây dựng hệ thống quản lý sân bóng hỗ trợ:
- Quản lý sân bóng
- Đặt sân online
- Quản lý bảng giá
- Quản lý đơn đặt sân
- Thống kê doanh thu
- Đánh giá sân bóng
